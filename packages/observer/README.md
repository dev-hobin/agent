# @hobin/observer

A spec-first rebuild of Observer for Pi.

Observer is intended to provide a local-first observation mode that follows standing inquiry loops across materials, reconciles developing memos, and promotes mature, source-linked knowledge into Zettelkasten records.

## Status

Observer v0.1 Slices 0–9 are implemented and Golden Path verified. The private package provides one sequential `observer_sidecar` Pi tool for Sidecar and model-owned One-shot observation, exact request-linked SourceRead/hydrate/record ancestry, read-only Memo reconciliation, user-approved durable Wrap, and fresh-process Standing Inquiry re-entry from local Markdown.

Current evidence includes 188 passing package tests, clean LSP diagnostics across 51 source files, zero TypeScript assertion expressions, a 41-file/zero-test npm tarball, fresh-consumer Pi 0.80.10 RPC, global Pi 0.82.1 discovery, current-tarball two-process re-entry, and bounded real-provider Sidecar and One-shot → Memo → Wrap transcripts. One-shot completion keeps Mode OFF and the Episode OPEN until Wrap settlement; notebook Markdown remains unchanged through observation and Memo, then changes only after approval, save, and readback validation.

These results establish bounded local single-instance behavior, not provider reliability, model semantic truth, crash/power-loss durability, concurrent execution, remote sync, Git ownership, or graph/vector database ownership.
