# 0.3.0: core specs with Claude Code and Codex implementations

**Status: prepared on branch `restructure/p1-hygiene`; not released.** Pushing and
publishing need separate approval.

## Breaking changes

- The marketplace is `hobin` (was `hobin-agent`); plugin IDs are `<plugin>@hobin`.
- Every capability is specified in `core/<id>/SPEC.md` and implemented separately for
  Claude Code (`claude/plugins/`) and Codex (`codex/plugins/`), each in that host's
  recommended form. The `packages/` layout, its npm packages, and the Pi adapters are
  removed.
- `hobin-developer` is replaced by `hobin-review`, `hobin-feature`, `hobin-stances`, and
  `hobin-skill-eval`; the standalone skills are retired (see the mapping below). Old
  resources are kept in `archive/`.

## Old to new

| 0.2.x | 0.3.0 |
| --- | --- |
| `hobin-developer:doctor`, review use of any judgment skill | `hobin-review:reviewing-code` |
| `specify`, `model`, `sketch`, `variation-judgment`, `naming-judgment`, `module-judgment` | `hobin-feature:developing-features` (knowledge: condition modeling, design surface, shared lenses) |
| `signal`, `abstraction-review`, `schedule`, `process-judgment`, `task-protocol-judgment`, `information-loss-judgment`, `verify`, `claim-evidence` | Shared lenses used by review and feature |
| `convention-judgment` | `hobin-stances:enforcing-conventions` |
| `adversarial-eval` | `hobin-skill-eval:evaluating-skills` |
| `delegation-gate`, `work-slice`, `inspectable-collaboration` | `hobin-stances:applying-stances` stances |
| `learning-checkpoint` | Checkpoint mode of `hobin-learning:exercise` |
| `visualize` | Retired |
| `hobin-learning` skills | Same names |

## Migrating an installation

```sh
# Claude Code
claude plugin uninstall hobin-developer@hobin-agent
claude plugin marketplace remove hobin-agent
claude plugin marketplace add /absolute/path/to/agent --scope user
claude plugin install hobin-review@hobin --scope user
# Codex
codex plugin remove hobin-developer@hobin-agent
codex plugin marketplace remove hobin-agent
codex plugin marketplace add /absolute/path/to/agent
codex plugin add hobin-review@hobin
```
