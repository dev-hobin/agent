# 0.2.2: standards-owned packages and native installation

**Status: release candidate; npm publication is pending.** The user has approved
release preparation. Do not claim publication until registry versions, tags and
artifact integrity have been verified. Published 0.2.1 contents remain unchanged.

## Changes

- Adopt Agent Plugins 1.0.0 at immutable upstream commit
  `bd383552095128f6effe895b9257cfd580a6d179`, alongside the retained Agent Skills
  baseline. Record authority, maturity, license, included/excluded scope,
  verification obligations and reconsideration triggers in the adoption register.
- Add portable `plugin.json` to both package roots and npm exports. Preserve
  `hobin-developer` and `hobin-learning`, synchronize npm and Claude compatibility
  metadata, and keep all 17 + 5 canonical Skills and references unchanged.
- Vendor the exact upstream manifest schema and Apache-2.0 license with SHA-256
  provenance. Expand `check:standard` to both resource specifications.
- Add independently host-shaped Claude/Codex catalogs pointing at the same package
  roots. They are distribution compatibility metadata, not a newly invented
  universal marketplace standard.
- Document persistent native user installation as the default; separate
  session-only `--plugin-dir` and optional flat Skill installation.
- Add opt-in model-free native checks using actual packs, temporary config,
  unrelated work directories, installed-byte comparisons and a same-named peer
  Skill. Preserve existing Pi integration behavior and resource controls. Isolate
  packed-Pi tests from the real HOME so personal flat Skills cannot shadow the
  fixture; continue asserting the real catalog, adapter and diagnostics.

## Verification scope

Portable checks cover schema shape, fixed discovery, path containment, exact
upstream bytes, metadata/catalog consistency, negative fixtures, extracted packs
and standalone relocated Skills. They run without Claude, Codex or Pi.

Executed locally on 2026-10-27:

- `pnpm check`: all 54 tests pass on Node 22.19.0 and 24.15.0, in addition to
  frontmatter validation of all 26 Skills and both portable package checks.
- A fresh relocated checkout with only the six root authoring dependencies passes
  `check:portable`, with the Pi dependency absent and fail-fast fake host binaries
  proving that Pi/Claude/Codex executables are not invoked.
- `pnpm check:claude`: both compatibility manifests and the marketplace pass;
  public-directory icon advice remains non-blocking.
- Both `check:install` probes pass; all installed supporting-resource bytes match
  source, and user enablement persists across two unrelated work directories.

Native probes target Claude Code 2.1.311 and Codex CLI 0.164.0. They check user
installation/persistence and component inventories, not live model behavior.
Codex's metadata inventory exposes `hobin-developer:model` and
`hobin-probe-peer:model` simultaneously with separate plugin IDs. Runtime method
adherence and reference selection remain unverified by these checks.

This release adds no custom installer, mandatory runtime, MCP server, automatic
flat-Skill migration, real global configuration change, or paid evaluation.
Publishing an npm version does not add marketplace catalogs to individual package
archives: those live in Git. Remote Git/registry installation is not implied by
local packed-artifact installation evidence.
