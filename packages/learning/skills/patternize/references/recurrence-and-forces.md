# Recurrence And Forces

Use this reference to distinguish an operational pattern from a topic cluster
and derive its runnable core.

## Pattern Evidence

Compare cases before naming the pattern:

```text
Case | Context | Problem | Forces | Move | Check | Consequence
```

Independent cases should vary in source, domain, project, representation, or
occasion. Repeated labels from one artifact are weak evidence.

## Recurring Core

A supported pattern has:

- **context:** the situation in which it becomes useful;
- **signals:** observable cues that activate it;
- **problem:** the recurring practical difficulty;
- **forces:** tensions or constraints that make the answer nontrivial;
- **axis:** the one criterion or transformation organizing the cases;
- **moves:** a small action, decision, diagnostic, or composition path;
- **checks:** observations that can fail a move;
- **consequences:** capabilities and accepted costs;
- **boundary:** when another pattern or no pattern is appropriate.

A shared topic, vocabulary, folder, or broad value is not a pattern.

## Constructive Thinking Operations

Use these selectively:

- observe conditions, anomalies, and successful movement;
- compare cases and near misses;
- recognize repeated relational structure;
- abstract accidental details into roles;
- model the forces and move dependencies;
- transform the model into a workflow or decision path;
- synthesize checks, consequences, and feedback.

Do not present these as a compulsory pipeline. Each operation must change the
pattern artifact.

## Move Contract

For every move state:

```text
Input:

Output:
Local check:
Failure if skipped:
```

If the path branches, state the discriminating condition. If results feed back
into prior judgment, represent the loop and its stop condition.

## Falsification

Test:

- one source case;
- one source-external transfer case;
- one boundary case where the pattern should not run;
- one skipped-move failure;
- one observation that would show the cases do not share the proposed axis.

Make no confidence claim broader than the evidence table. It supports only the
stated recurrence and transfer result.
