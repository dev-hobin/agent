| Plugin | Version |
|---|---|

Specs are unchanged. Investigation and decisions: `docs/plans/2026-11-06-feature-hook-cross-repo-and-run-state.md`.

## Changes

- **Records outside the cwd.** A shell command that writes a record after `cd`-ing (or
  `git -C`, `pushd`, `--dir=`) into a directory outside the hook's cwd now adds that record to
  the session ledger. The hook also looks under every existing directory the command names,
  with the same PreToolUse stamp and checked-out filters. `/`, the home directory and system
  folders are never walked.
- **Run state.** `scenarios.mjs run` marks every result `running` and saves the record after
  each scenario and after the existing tests, so an interrupted run leaves `running` instead
  of the previous run's passes. It keeps a marker in the temp directory while it runs.
  `check` reports `running` as a run in progress or interrupted, and the Stop hook says which
  (still running with pid and start time, or interrupted). Stop still blocks on it.
- **Not added:** a partial `run --only`, because it cannot show the other scenarios still pass
  after a code change.
