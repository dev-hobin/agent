## Changes

- **Records tools (MCP).** hobin-feature ships a stdio MCP server, `hobin_feature`, with the
  tools `init` (create a record from the template; never overwrites), `register` (an existing
  record), `check` (report what a record still needs; read-only) and `decline` (a non-empty
  reason). Paths are absolute. The server keeps no session state and runs no project command.
  Claude: `.mcp.json` with `${CLAUDE_PLUGIN_ROOT}`; tools `mcp__plugin_hobin-feature_hobin_feature__*`.
  Codex: `.codex-plugin/plugin.json` `mcpServers: ./.mcp.json`, `cwd` the plugin root, explicit
  startup and tool timeouts, annotations that `auto` approval accepts; tools `mcp__hobin_feature__*`.
- **Registration only from structured tool calls.** A successful `init`, `register` or `check`
  call registers its `tool_input.path`; `decline` records its reason; edit tools still register
  the exact path they wrote. Shell commands, their output, environment variables and temp
  directories register nothing: the shell-text inference of 0.5.1 is gone.
- **State in the plugin data directory** (`CLAUDE_PLUGIN_DATA`, Codex `PLUGIN_DATA`), removed on
  SessionEnd and pruned after 7 days.
- **Obligation.** Starting developing-features (Claude: the Skill tool or a
  `/developing-features` / `/hobin-feature:developing-features` prompt; Codex: a
  `$developing-features` prompt or reading this plugin's SKILL.md) makes Stop ask for a record,
  naming the host's `init`, `register` and `decline` tools.
- **Run state in the record.** `scenarios.mjs run` (still in the shell) marks results `running`
  and writes `verification.run = { startedAt, lastProgressAt }`, saves after each result and
  deletes it when it ends (also on a throw). `check` and Stop say the run has not finished: wait
  if it is still running, run it again if it stopped; on Claude, Stop also says when background
  tasks are still running.
- **Hooks.** Claude: UserPromptSubmit, PostToolUse (`Write|Edit|MultiEdit|Skill` and the records
  server's full tool prefix), Stop, SessionEnd. Codex: UserPromptSubmit, PostToolUse, Stop,
  SessionEnd. Same script on both hosts, told the host by hooks.json.
- **CLI.** `scenarios.mjs init|run|check|decline` stay for people; they register nothing.

## Upgrading

Sessions must create or register their record through the records tools (or write it with an
edit tool); a record touched only from the shell is not the session's. On Claude Code, allow
`mcp__plugin_hobin-feature_hobin_feature__*` to skip the per-call permission prompt.
`pnpm check`: 188 tests pass, 0 fail. Not run: paid host evals and a live model session with 0.6.0 installed.
