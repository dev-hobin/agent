# Source Insight Synthesis

Use this reference to organize what one prose source taught across several
chunks, examples, questions, or visual explanations.

## Synthesis Unit

An insight bundle is source-bound but reusable in discussion:

```text
Source scope:
Faithful claim or model:
Insight:
Evidence and locator:
Teaching example or contrast:
Boundary or likely misreading:
Practical consequence:
Open question:
Evidence level: source claim | interpretation | hypothesis
```

Do not fill every field mechanically. Include enough local explanation that the
reader can recover the learning move without reopening the source.

## Derivation

1. Reconstruct the source's intended reader change.
2. Collect claims, examples, caveats, terms, sequence, and reader questions that
   materially support that change.
3. Separate what the source states from interpretation and new hypotheses.
4. Group evidence around one insight at a time.
5. Split bundles when they answer independent practical questions or have
   different boundaries.
6. Derive consequences from the source model, contract, semantics, or procedure.
7. Preserve unresolved counterexamples and uncertainty.

## Selective Thinking Operations

Use only operations that alter the synthesis:

- **Observe:** notice exact wording, sequence, visual structure, or anomaly.
- **Compare:** contrast nearby examples, terms, states, or failure cases.
- **Recognize a pattern:** identify repeated source movement without claiming
  cross-source generality.
- **Abstract:** name the relation that explains examples while preserving source
  anchors.
- **Model:** express execution, state, contract, data, or causal structure.
- **Transform:** change prose into a table, trace, diagram, rule set, or example
  when that representation lowers interpretation cost.
- **Synthesize:** connect evidence, boundary, and consequence into a coherent
  insight.

This is a repertoire, not a seven-step pipeline.

## Failure Checks

Revise when the result is:

- a chronological transcript;
- a generic summary without evidence;
- a list of quotations without a reconstructed learning move;
- practical advice disconnected from the source;
- several independent insights collapsed into one slogan;
- a source-independent concept claimed from one source without transfer tests;
- a storage schema or file plan substituted for the insight synthesis itself.

## Stop

Finish when every consequential insight is traceable to its source scope, has a
boundary, and exposes whether it is a source claim, interpretation, or
hypothesis. If file delivery is requested, write this completed result as plain
Markdown after the synthesis judgment.
